# 돈의 방정식 (The Art of Spending Money)

**저자:** 모건 하우절 (Morgan Housel)
**분석 관점:** 1976년생, 2026년 50세 은퇴 / 순자산 약 000억 원 / 경제적 자유 평생 유지

> **"부(富) = 가진 것 − 원하는 것 (Wealth = What You Have − What You Want)"**

---

## 투자 철학 요약

| 원칙 | 내용 |
|---|---|
| 포트폴리오 구조 | 2분할: 고수익 추구 + 자본 보존 |
| 생활비 인출 | 총자산의 연 2~3% (작년 수익금의 1/3 이내) |
| 유동성 | 6개월 생활비를 현금성 자산/안전자산으로 보유 |
| 분산 | 미국 50~60%, 중국+한국 30~40%, 기타+글로벌 10% |
| 삶의 철학 | 돈은 수단, 건강·가족·배움·경험·사회 기여가 목적 |
